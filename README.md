# 手眼标定方法对比

对比两种 eye-to-hand 手眼标定方法的原理，并给出一套分层解耦的标定方案：

- **方法 A**：末端贴 AprilTag，单目 PnP 得到 Tag 位姿，求解 `AX = YB`
- **方法 B**：末端激光测距仪打出光斑，双目三角化后与正运动学换算的点做 3D–3D 刚体配准
- **第 7 节**：两种方法的误差来源，哪些误差能分开、哪些原理上分不开
- **第 8 节**：分层解耦标定方案（相机、激光测距、机械臂 + 激光射线、手眼外参、独立验证）
- **第 9 节**：多项式补偿与分层标定在同一批实测打靶数据上的对比：补偿的做法、分层 9 个参数各对应哪个部件、参数错误的"指纹"、两天的数字

页面包含可交互的 3D 演示（three.js），在浏览器里实时运行两种求解算法。

在线页面：https://haoxiangntu.github.io/handeye-calib-comparison/

## analysis/

离线分析脚本，只读取已经录好的数据或在 URDF 上做仿真，不连接任何硬件。数据本身不在本仓库中。

| 脚本 | 内容 | 对应章节 |
|---|---|---|
| `identifiability.py` | 两种方法在实际采集姿态下的线性化可辨识性 | 7.8 |
| `decoupled_dryrun.py` | 用已录样本做“只用一套测量系统”的检验：相机单独、机械臂 + 激光单独、控制器位姿对 URDF、相机对机械臂的尺度 | 8.1 |
| `layer3_plate_sim.py` | 平面约束法仿真：平板摆法和姿态数对关节零位、激光射线精度的影响，含非线性蒙特卡洛 | 8.4 |
| `layer4_extrinsic_sim.py` | 只解 6 个外参时的精度，以及相机尺度误差未先消除时的后果 | 8.4 |
| `compensation_vs_layered.py` | 在同事的打靶记录上比较 44 系数多项式补偿和 9 参数分层模型：同一口径误差、相机无关的激光射线估计、交叉验证、小样本、跨数据集、单滑块增量 | 9 |
| `compensation_config_2026111*.json` | 上一脚本的两份配置：报告、标定文件、板配准、校正后内参的相对路径 | 9 |
| `kin.py` | 上面几个脚本共用的正运动学（URDF + 改进 DH 参数误差） | — |

每个脚本旁边的 `*_results.json` 是本次运行的输出。
